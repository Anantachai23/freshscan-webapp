# Datasetimage — ภาพอ้างอิงจริงสำหรับปรับเทียบความแม่นยำ

## สิ่งที่โฟลเดอร์นี้ทำ (และไม่ได้ทำ)

โฟลเดอร์นี้ **ไม่ได้มาพร้อมรูปภาพ** ผมไม่มีคลังภาพถ่ายจริงของอาหารทะเลสด/ไม่สดให้ใส่มาให้ — 
ต้องใส่รูปจริงที่คุณถ่าย/มีสิทธิ์ใช้เองเท่านั้น (เพื่อความถูกต้องและไม่ผิดลิขสิทธิ์)

ระบบวิเคราะห์หลักของแอป (`src/lib/freshnessAnalyzer.ts`) **อ่านค่าพิกเซลจริงจากภาพที่อัปโหลด** อยู่แล้ว
(ความสว่าง, ความอิ่มของสี, สัดส่วนรอยดำ, สัดส่วนสีเหลือง/น้ำตาลหม่น, ความสม่ำเสมอของสี, ความคมของพื้นผิว)
— นี่คือ **heuristic ที่อธิบายได้ ไม่ใช่ deep learning model ที่เทรนจากภาพ**

โฟลเดอร์นี้ + สคริปต์ `npm run calibrate` เพิ่มชั้น **"ปรับเทียบ" (calibration)** อีกชั้นหนึ่ง:
สคริปต์จะอ่านรูปจริงที่คุณใส่ไว้ คำนวณค่าเฉลี่ยของแต่ละหมวด (เช่น ปลา-สด, ปลา-ไม่สด)
แล้วบันทึกเป็น `src/data/calibration.json` — เวลาแอปวิเคราะห์ภาพใหม่ จะเทียบว่าภาพนั้น
"ใกล้เคียง" กับค่าเฉลี่ยของหมวดไหนมากที่สุด แล้วปรับคะแนนขยับเล็กน้อย (ไม่เกิน ±2.5 จาก 20 คะแนน)
ไปทางหมวดนั้น — เป็นการปรับเทียบด้วยข้อมูลจริง ไม่ใช่การเทรนโครงข่ายประสาทเทียม

**สรุปตรงๆ สำหรับพรีเซนต์กรรมการ:** พูดได้ว่า "ระบบวิเคราะห์จากค่าพิกเซลจริงของภาพ และมีการ
ปรับเทียบ (calibrate) ด้วยชุดภาพอ้างอิงจริง" — ไม่ควรพูดว่าเป็น "AI ที่เทรนจากภาพหลายพันรูป"
เพราะไม่ตรงกับสิ่งที่ระบบทำจริง

## วิธีใช้

1. ใส่รูปภาพจริง (.jpg / .jpeg / .png) ลงในโฟลเดอร์ให้ตรงหมวด เช่น:
   - `Datasetimage/fresh/fish/` → รูปปลาสด
   - `Datasetimage/not_fresh/fish/` → รูปปลาไม่สด
   - ทำแบบเดียวกันกับ `shrimp` (กุ้ง), `shellfish` (หอย), `squid` (ปลาหมึก)
2. แนะนำอย่างน้อย **5-10 รูปต่อหมวด** (ยิ่งมากยิ่งแม่นขึ้น ระบบต้องการอย่างน้อย 3 รูปต่อหมวดถึงจะเริ่มใช้ปรับเทียบ)
3. รันคำสั่ง:
   ```
   npm run calibrate
   ```
4. สคริปต์จะสร้าง/อัปเดต `src/data/calibration.json` อัตโนมัติ
5. รัน `npm run dev` หรือ `npm run build` ใหม่ — แอปจะใช้ค่าปรับเทียบนี้ทันที

## โครงสร้างโฟลเดอร์

```
Datasetimage/
  fresh/
    fish/
    shrimp/
    shellfish/
    squid/
  not_fresh/
    fish/
    shrimp/
    shellfish/
    squid/
```

## ข้อควรระวัง

- รูปควรถ่ายในสภาพแสงใกล้เคียงกับที่จะใช้งานจริง (เช่น แสงในตลาด/ห้องครัว) เพื่อให้ค่าปรับเทียบสมจริง
- อย่าใช้รูปที่มีลิขสิทธิ์ของผู้อื่น (เช่น ดาวน์โหลดจากเว็บ) — ใช้รูปที่คุณถ่ายเองหรือมีสิทธิ์ใช้ชัดเจน
- โฟลเดอร์นี้และรูปภาพจะไม่ถูกอัปโหลดขึ้น production build (ดู `.gitignore`) ยกเว้นไฟล์ `calibration.json`
  ที่สคริปต์สร้างออกมา ซึ่งเป็นแค่ตัวเลขค่าเฉลี่ย ไม่ใช่ตัวรูปภาพ
